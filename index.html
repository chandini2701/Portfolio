My Projects

Projects I have worked on

01. Federated Learning with LLM Automation

Web-Based System

Developed a web-based system combining Federated Learning with Large Language Model (LLM) automation. The project brings together distributed machine learning concepts and transformer-based language processing in a web application.

Federated Learning enables machine learning models to learn from distributed data without requiring all training data to be gathered in one central location. LLM automation supports language-based processing within the application.

Key Concepts: Federated Learning, distributed machine learning, model training, transformer-based language processing, and web application development.

Technologies Used: Python, JavaScript, Flask, Express.js, Scikit-learn, PyTorch, FLAN-T5 Transformer, Tailwind CSS, Axios, and Socket.IO.

02. Foodies Hubb

Online Food Delivery Website

Foodies Hubb is a static online food delivery website designed to provide users with a simple and convenient way to explore restaurants and their food menus.

Users can explore restaurant listings, view food items, navigate through login and registration pages, and interact with cart, checkout, and order history pages. The website focuses on a clear layout and an easy-to-use browsing experience.

Key Features: Restaurant listings, restaurant menus, login page, registration page, shopping cart, checkout interface, and order history interface.

Technologies Used: HTML5, CSS3, JavaScript, Git, and GitHub Pages.

Project Type: Front-end static website.
